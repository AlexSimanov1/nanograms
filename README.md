# Nanograms

Веб-приложение для решения японских кроссвордов (нанограмм).
Проект находится в стадии разработки и является pet-проектом.

## Запуск

Для запуска проекта требуется Docker.

```bash
docker compose up
```

После запуска приложение доступно по адресу `http://localhost:8080`.

Порт и другие параметры конфигурации могут быть изменены через переменные окружения.

## Статус

Проект находится в активной разработке.

## MVP

- решение японских кроссвордов в браузере;
- поддержка кроссвордов до 20×20;
- desktop и mobile интерфейс;
- каталог кроссвордов;
- сохранение незавершённого прогресса в браузере;
- таймер;
- проверка решения.

## Принцип проекта

Это pet-проект.

Архитектура намеренно остаётся простой: никаких БД, микросервисов и другой инфраструктуры, которая не нужна для текущего продукта.

При этом границы между frontend, backend, domain logic и storage должны оставаться достаточно чёткими, чтобы в будущем при необходимости разделить frontend и backend без полной переделки приложения.
