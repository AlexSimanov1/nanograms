# Nanograms

Веб-приложение для решения японских кроссвордов (нанограмм).
Проект находится в стадии разработки и является pet-проектом.

## Запуск

Для запуска проекта требуется Docker.

```bash
docker compose up
```

После запуска приложение доступно по адресу `http://localhost:8080`.

`docker compose` поднимает два сервиса одной командой:

- `backend` — Go API (`/api/v1/*`);
- `frontend` — nginx, раздаёт собранное приложение и проксирует запросы к `/api` на backend.

Из браузера наружу публикуется только порт `8080` (frontend), поэтому приложение
работает как единая точка входа без CORS.

При изменении frontend/backend пересобрать образы:

```bash
docker compose up --build
```

### Разработка (локально, без Docker)

- Backend: `go run ./cmd/server` → API на `:8080`.
- Frontend: `cd frontend && npm install && npm run dev` → Vite dev-сервер на `:5173`
  с проксированием `/api` на `:8080`.

Порт и другие параметры конфигурации backend могут быть изменены через переменные
окружения (`HTTP_ADDR`, `PUZZLE_DIR`).

## Статус

Проект находится в активной разработке.

## MVP

- решение японских кроссвордов в браузере;
- поддержка кроссвордов до 20×20;
- desktop и mobile интерфейс;
- каталог кроссвордов;
- сохранение незавершённого прогресса в браузере;
- таймер;
- проверка решения.

## Принцип проекта

Это pet-проект.

Архитектура намеренно остаётся простой: никаких БД, микросервисов и другой инфраструктуры, которая не нужна для текущего продукта.

При этом границы между frontend, backend, domain logic и storage должны оставаться достаточно чёткими, чтобы в будущем при необходимости разделить frontend и backend без полной переделки приложения.
